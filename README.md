# Sweet Bakery

Create a simple, beautiful bakery website called "Sweet Bakery".

Use a soft pink, white, and cream color theme with cute dessert images and a modern, clean design.

The website must have exactly 7 main sections:

Home – Welcome message and featured desserts.

Cakes – Display cakes with images, names, and prices.

Cupcakes – Display different cupcakes.

Cookies – Display cookies with prices.

Drinks – Display hot and cold drinks.

About Us – Short information about the bakery.

Contact Us – Contact form, phone number, and location.

Also create:

Sign In page (email and password).

Sign Up page (name, email, password, confirm password).

Logout button.

Simple navigation bar.

Responsive design for mobile and desktop.

Make the website easy to use, visually attractive, and beginner-friendly.

Use sample products and prices. Keep the functionality simple and avoid complicated features.
